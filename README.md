# llm-gateways-tut
Implementation and production patterns for LLM Gateways using LiteLLM &amp; LangChain. Explores multi-provider unified APIs, automatic fallbacks, in-memory caching, cost tracking, latency-based routing, audit callbacks, and custom LiteLLM guardrail hooks (PII redaction, prompt injection defense, and topic filtering).(Inspired by Krish Naik's tutorial)
